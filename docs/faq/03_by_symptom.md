# 🔍 按症状查原因

> 遇到问题先在这里找最像的症状。每条先说**最可能的原因**，再说**怎么办**。找不到就联系客服 [@oxbaimao](https://t.me/oxbaimao)，并把软件里复制的诊断信息一起发过去。

---

## 一、安装、激活与更新

### 打开软件就提示缺少运行库或闪退
- **原因**：Windows 缺少 Visual C++ 运行库，或安装目录被杀毒软件隔离。
- **怎么办**：安装微软官方 `Visual C++ Redistributable 2015–2022`；杀毒软件里把安装目录加入信任并恢复被隔离的文件。

### Windows 提示「已保护你的电脑」/ macOS 提示「无法验证开发者」「已损坏」
- **原因**：软件还没有购买代码签名证书（macOS 也没有 Apple 公证），系统对新软件会提醒。
- **怎么办**：见 [下载与安装](../getting_started/desktop_install.md) 里的放行步骤；不是病毒。

### 激活失败，提示设备公钥不一致 / 403
- **原因**：重装系统、清了数据目录、虚拟机被重置后，这台设备的密钥变了。
- **怎么办**：**用这台设备之前激活过的那张卡密再激活一次**，服务器会自动恢复绑定（同一台设备 30 天最多 3 次）。拿一张没用过的新卡密直接激活不行，会提示先用原卡密。建议固定数据目录。

### 激活或检查更新一直连不上授权服务器
- **原因**：公司或代理网络拦截并替换了 HTTPS 证书。
- **怎么办**：5.0.12 起软件同时信任系统证书库和自带证书库；仍失败时，把你们出口的根证书放到数据目录的 `extra_ca.pem`，升级不会覆盖。

### 点「检查更新」提示没有适用于我系统的安装包
- **原因**：该平台这一版没有发布。例如 6.0.1 没有出 macOS Intel 版。
- **怎么办**：到官网或 Release 页面手动下载该平台最新的包（macOS Intel 当前是 6.0.0）。

### 猫管家的设置窗口反复报错，或文字互相压住
- **原因**：6.0.0 的已知问题。
- **怎么办**：升级到 **6.0.1**。

## 二、账号

### 一批账号都显示「错误」
- **原因**：最常见的是**同一个 session 被多处同时使用**（通常是从号商买来的 tdata / session 转换出来的号，卖家手里还留有同一把登录密钥）。Telegram 会因此让会话失效。
- **怎么办**：软件会显示具体原因，不会覆盖账号状态。先确认这个 session 只在一处使用；买来的号建议用「账号接管」换成自己的新会话。

### 发消息失败，是账号被限制了吗？
- **不一定**。单个群里被禁言、对方设置了隐私，都不等于账号受限。
- **怎么办**：用「账号限制检测」做一次核实（它会读取 @SpamBot 的**新**回复）；检测结果为「未核实」时**不要**当成正常，也不要据此清理账号。会清理或移走账号数据的动作，只处理「已核实」受限的号。
- 申诉见 [01. 账号管理](../manual/01_account.md) 里的 SpamBot 申诉；「已提交」只表示申诉资料已提交，**是否解除要再用检测状态核实**。

### 导入的 session 显示待连接 / 无法登录
- **怎么办**：检查代理能否直连 Telegram DC；检查该 session 是否已在其他设备被强制登出。

## 三、发送与采集

### 语音条发不出去 / 提示没有 ffmpeg
- **怎么办**：Windows 与 macOS 安装包已内置转码组件；Linux 版需要系统里装有 ffmpeg。

### 群发提示被限流 / 额度不足
- **原因**：账号风控额度（按号龄分档）到了，软件会给出人话原因。
- **怎么办**：等额度恢复、换其他账号，或在设置里按需调整（可自定义 / 关闭，**关闭后封号风险自负**）。

### 强拉后对方没进群
- **原因**：对方的隐私设置不允许被拉。
- **怎么办**：软件会自动改发私信邀请，但只算「已发邀请」，不会冒充「已拉入」；以回读核实的结果为准。
