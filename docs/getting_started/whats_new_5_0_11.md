# 5.0.11 更新说明（草稿，未发布）

> 写给付费客户的人话版。没在真实 Telegram 里验证过的地方，下面都写明了。

## 入群验证：能应付更复杂的场景了
- **多步验证**：点「申请加入」后，机器人在私聊里发消息、要先关注频道、再点「我已关注」、再出人机验证、再选图 / 输数字……软件会在机器人私聊里一步一步走完，机器人把原消息改成下一题也认得出来。**通过与否以账号在群里能不能发言为准**，没核实不算通过。
- **图片题**：看图 AI 读验证码 / 选图。**设置 → AI 里新增「 测试连接」**：真实调一次文字 AI，再发一张写着数字的图给看图 AI，告诉你是否连通、延迟多少、能不能读对。用中转站自定义模型名（比如 `gpt-6.1-sol`）被误判成「看不了图」的，测试读对后会自动勾上「强制支持看图」，保存后生效。
- **语音题**（听语音输入数字）：设置里新增「语音识别」（接口要支持 OpenAI 兼容的 `/audio/transcriptions`，模型默认 `whisper-1`）。没配置、或接口不支持时，会直接告诉你原因，不会瞎编答案。
- **新增「 验证中心」**（暖号页）：批量加群后没通过的群，在这里直接看到验证消息（文字 / 按钮 / 图片 / 语音），可以点按钮、回复文字、一键交给 AI 再试、打开网页验证。
- **日志不再刷屏**：同一个失败原因只写一次，之后写「原因同上」；「需要手动处理」按群合并。
- **软件不会替你做的事**：分享手机号 / 位置 / 联系人、支付、用 Telegram 登录外部网站——这类按钮永远不点，会标明需要你自己处理。

## 给 Agent（MCP）
- `tg_verify_group_join` 新增读取机器人私聊（`bot_dms`：文字、按钮类型、频道链接、图片 / 语音文件、语音识别文字）；`tg_solve_captcha` 新增 `chat`（在机器人私聊里点 / 回）、`join_channels`（先加频道）、`start_param`、`wait_for_reply_seconds`（等机器人下一步）。Agent 可以像真人一样一步步过群，不必再去碰 session 文件。这两个工具只是加了参数，没有新增工具。

## 语音、圆形视频、电话（给 Agent / MCP）
- **发语音条、圆形视频**：早就能用——`tg_unified_send` / `tg_smart_broadcast` 的 `voice_path`（自动转 Opus）、`video_note_path`（自动裁成正方形、最长 60 秒），以及「电话 → 语音条 → 文字」这类触达顺序。需要有 ffmpeg：Windows / macOS 安装包自带，**Linux 版不内置，请先装好系统的 ffmpeg**。
- **新增 `tg_voip_call`（MCP 工具数 56 → 57）**：让账号像真人一样打 Telegram 语音电话。
  - `ring`：响铃 2~3 秒后挂断，对方留一条未接来电（不需要额外组件）。
  - `dial` / `say` / `listen` / `hangup`：真实拨打、在通话里播放一段音频（你自己做语音合成）、听对方说 N 秒（可用设置里的语音识别转成文字）、挂断。对话回路由 Agent 自己驱动，软件不替它说话。
  - **默认只预览**（`dry_run=true`），真打要写入权限、计入账号风控额度（红灯账号被拦）；对方关了通话权限 / 拒接 / 忙线 / 没接都如实返回；一通电话最长保持 10 分钟自动挂断。
  - **实时通话需要可选组件** `py-tgcalls`（见 `requirements-voip.txt`）和系统 ffmpeg；没装时会直接告诉你原因。本次发布的 Linux 包是否带上了该组件，以包内说明为准。**实时通话没有在真实通话里验证过**，请先用自己的小号测试。

## 账号安全
- 新增命令行工具 `python -m tools.rotate_sessions`：session 泄露时，用旧会话收验证码登录出一个全新设备，确认可用后登出旧会话，让泄露的副本作废。「踢掉其他设备」对 session 泄露没用（副本和软件用的是同一把密钥）；同一个 session 在两个 IP 同时使用会被 Telegram 直接作废。**界面里还没有按钮，暂时只能用命令行**。

## 注意
- 以上**都没有在真实 Telegram 里验证过**（申请加入制的群、真实验证机器人的多步流程、语音题、中转站的语音识别和看图）；请先用小号小批量试。
- Cloudflare 一类网页验证仍然需要你在电脑前（会弹出无痕窗口），不能保证无人值守。
