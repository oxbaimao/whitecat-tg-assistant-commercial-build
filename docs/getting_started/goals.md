# 🧭 你想做什么？按目标找功能

> 不知道从哪开始？找到你的目标，照着链接读对应的那一篇就行。第一次使用建议先读 [试用、购买与激活](activation_and_trial.md)，装好软件后按下面的「第一周路线」走。

---

## 一、第一周路线（新手推荐）

| 第几步 | 做什么 | 读这篇 |
| :--- | :--- | :--- |
| 1 | 装软件、激活 | [下载与安装](desktop_install.md) → [试用、购买与激活](activation_and_trial.md) |
| 2 | 导入或登录账号 | [01. 账号管理](../manual/01_account.md) |
| 3 | 给账号配代理（一号一 IP） | [02. 代理管理](../manual/02_proxy.md) |
| 4 | 采集一批目标用户 | [05. 成员采集](../manual/05_collect.md) |
| 5 | 先小批量发第一条私信 | [08. 私信群发](../manual/08_private_send.md) |
| 6 | 开自动回复，不丢客户 | [18. 私信自动回复](../manual/18_auto_reply.md) |

## 二、按目标找功能

### 我想找到客户
- 从别人的群里采集成员、最近发言的人 → [05. 成员采集](../manual/05_collect.md)
- 监听群里的关键词，命中就记录线索并通知我 → [06. 关键词监控](../manual/06_keyword_monitor.md)
- 盯同行的群，截流有购买意向的人 → [16. 间谍获客](../manual/16_spy_engine.md)
- 手里有一批用户名 / 链接，想分清是人、群、机器人还是频道 → [13. 目标分类筛选](../manual/13_target_classifier.md)
- 判断一个账号安不安全 → [12. 安全检测](../manual/12_security_check.md)
- 研究同行的群或机器人怎么运营 → [22. 运营模式分析](../manual/22_operation_analysis.md)

### 我想联系客户
- 给一批用户发私信（文字 / 图片 / 语音 / 圆形视频） → [08. 私信群发](../manual/08_private_send.md)
- 往一批群里发广播 → [07. 统一群发](../manual/07_unified_send.md)
- 把用户拉进我的群 → [09. 强拉加群](../manual/09_force_invite.md)
- 客户私信我，我想自动回复 → [18. 私信自动回复](../manual/18_auto_reply.md)
- 用机器人给访问过我机器人的用户群发 → [17. 访客机器人](../manual/17_visitor_bot.md)

### 我想运营群和频道
- 批量建群 / 建频道 → [21. 批量建群建频道](../manual/21_batch_create.md)
- 批量加入别人的群，顺便养号 → [10. 批量加群与养号](../manual/10_warmup.md)
- 让多个账号在群里聊起来 → [15. AI 炒群](../manual/15_ai_hype.md)
- 把别的频道的内容搬到我的频道 → [19. 频道克隆搬运](../manual/19_channel_clone.md)

### 我想管好账号
- 导入、检测、分组账号 → [01. 账号管理](../manual/01_account.md)
- 改名字、头像、简介 → [11. 资料修改](../manual/11_profile.md)
- session 和 tdata 互相转换 → [03. 安全与格式转换](../manual/03_convert.md)
- 账号被限制了 → [常见问题：按症状查原因](../faq/03_by_symptom.md)
- 想长期不被封 → [工业级防风控与账号养号秘籍](../faq/01_anti_ban.md)

### 我想让 AI 帮我干活
- 在软件里用一句话下指令 → [23. 猫管家](../manual/23_cat_butler.md)
- 在手机上遥控电脑上的软件 → [24. 手机遥控](../manual/24_phone_remote.md)
- 让 Claude / Cursor 等外部 AI Agent 接管 → [MCP 一键配置](../mcp/01_quickstart.md)
