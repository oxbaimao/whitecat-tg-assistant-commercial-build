# 5.0.17 更新说明

> 写给付费客户的人话版。没在真实环境验证过的地方，下面都写明了。
> **发布平台以实际发布为准。**

## 新功能：福利中心（首页「福利中心」按钮）
- 领取合作福利，现在是「Muse AI 免费试用账号」：每个账号可领 1 个，领取记录自动保存，已领过的账号不会重复领取。
- 点账号表里的任意一行就能勾选；勾选后「领取选中账号」按并发数同时进行（默认 3 个，可在窗口里自定义 1~20，会记住；调高后如果有账号失败（限流 / 超时），会弹窗提醒并可一键调低），每个号做完后有间隔；中途可以停止。账号很多时调大更快，遇到限流就调小。
- 领到的账号可以「导出选中为 txt」：每行「邮箱 | 取码网址」，附带使用教程，直接交付给使用者。软件**不保存**账号凭证——导出时从该账号的机器人聊天记录里只读重新取。
- 启动后（以及之后新导入账号时）如果还有在线账号没领福利，会弹窗提醒；可以「忽略本次」。
- 「福利投稿」：有更多 Telegram 福利（关注频道、群里回复关键词等）欢迎投稿，窗口里有联系入口。
- 如果某个账号领取成功、但软件没能读到回执（Telegram 回了本软件暂时解析不了的消息类型），会显示「未确认」而不是「失败」；你登录账号确认领到之后，可以勾选它点「标记为已领取」。

## 新功能：账号级「全托管」
- 账号页右键「设为全托管」：你把这个账号整体授权给 Agent，发送额度、号龄分级、红灯暂停都不再拦截，也不再逐次确认；每个受控动作都写入审计日志。随时可以退出。
- 不会绕过：账号接管未完成时的暂停、删除账号 / 设置两步验证各自的确认口令、Telegram 对封禁账号本身的拒绝。滥用可能导致账号被限制或封禁，风险由你承担。

## MCP：58 → 60 项工具
- 新增 `tg_chat_manage`：账号的全部会话清单（群 / 频道 / 私聊 / 机器人 + 你在其中的身份）、读任意会话历史（不标已读）、按链接 / ID 退群退频道（含订阅的广播频道）、Telegram 层拉黑 / 解除拉黑、删除会话、删除联系人。必须指定账号；写入类动作默认只预览，做完回读核实。
- 新增 `tg_benefits`：福利中心的 MCP 同源工具（默认只预览）。
- 采集成员 / 安全检查 / 目标分类 / 批量建群新增 `phone`；私信自动回复 / 间谍获客 / AI 炒群新增 `phones`。不指定账号时会自动避开受限、冻结、封禁的号，并在返回里写明实际用了哪个账号；指定了账号就只用它，不在线直接报错，不会悄悄换号。
- `tg_prune_restricted_accounts` 新增账号范围，并且 **MCP 默认只预览**（以前一次调用就会隔离全部符合条件的账号）。
- 官方「新手提示词」：设置页一键复制，粘贴给任何 Agent 即可开工；已接好 MCP 的客户端也可以直接取（提示词 `whitecat_starter`）。

## 修复
- 笔记本 / 窗口矮时页面控件被压扁、文字叠在一起：现在页面保持自己的最小高度，窗口不够高时出现竖向滚动条。
- 删除同号的重复账号记录时，会连带删掉另一条在线记录共用的会话文件：现在只移除这条记录，文件留给另一条。
- 安全检查里「共同群组」一直为空：已修复，查询失败时会明确标出，不再和「真的没有共同群」混淆。
- `--serve-mcp` 反复静默退出的排查：现在收到终止信号会写日志后退出，终端 / SSH 关闭（SIGHUP）不再让它一起退出，每 10 分钟一行心跳（含内存），启动时会写明上一次有没有正常退出。**这只是诊断，没有复现过那个问题，不保证已修好。**
- 「database is locked」在自动重试时不再按错误记录。
- SpamBot 西语受限回复补充了几个常见译法的识别（样本是按常见译法构造的，不是真实抓取）。

## 注意（如实）
- 福利领取主流程在真实 Telegram 里跑通过（两个账号领取成功），但导出 txt、手动标记、启动提醒弹窗、新增的会话管理 / 福利 MCP 工具、全托管开关、`--serve-mcp` 退出诊断，**没有在真实账号上验证过**，只有模拟测试。会话管理里的退群、拉黑、删会话是不可逆动作，请先用小号。
- 少数账号可能收到比软件内置协议库（Telethon 1.45，已是最新发布版）更新的消息类型：福利领取会显示「未确认」，读取会话 / 采集等其他功能在这类账号上也可能遇到同样的解析问题。
- 「重启后误报线路变更」没有复现，没有改动。
