# 白猫 TG 助手 5.0.18 更新说明（面向用户）

> 相比 5.0.17：福利中心重做（Muse 10 亿 Token 邀请码领取 + 新增「机器人邀请」）、批量接管更好用、账号与会话工作台一批体验修复、群发 / 私信少走弯路、Agent（MCP）更可信。MCP 工具数不变（60 个）。
> 平台：Windows（应用内更新）· Linux 便携包。macOS 本版暂不更新。

---

## 一、频道公告（可直接转发）

** 白猫 TG 助手 5.0.18 来了**

这一版主要做了四件事：

** 福利中心升级**
• Muse 福利现在是 **10 亿（1B）Token 邀请码领取**：填你自己的 Muse 邀请码，勾选的账号**用同一个码一起领**；暂时没码也行，账号会停在「等待邀请码」，填码后一键补交
• 新增 **「机器人邀请」**：粘贴任意 `t.me/机器人?start=参数` 链接，选中的账号逐个带参数进入机器人——每一步都有日志、整批有汇总、结果可导出 CSV；机器人回复「已确认」或「无法被邀请」会如实标出来
• 提醒方式改了：不再启动就弹窗，改成首页「福利中心」角标 + 一条提示条，可「今天不再提醒」

** 账号与接管更顺手**
• 「断开」现在**只断开选中的账号**（没选才断全部，并先确认）
• 批量接管：账号池里在线的号也能直接勾选（开始前自动断开）；新增「提供 2FA」「从列表移除」；软件里记录过的 2FA 接管时会**自动使用**（以前会误报「没提供 2FA」）
• 接管结果清单更准确：卖家密钥是否失效、为什么没预先清理其他会话，都写清了原因
• 「待连接」的账号会写明原因（例如 Session 没登录），不再让人猜
• 多账号会话工作台新增筛选：**全部 / 私聊 / 群组 / 机器人**

** 群发与私信少走弯路**
• 不存在的 @用户名只试一次，不再每个账号各试一遍刷屏
• 带国家码但没写「+」的手机号（如 27631558131）现在会按手机号识别，不再当成用户 ID
• 冻结 / 受限账号解析不了用户名时，会明说是账号原因，不再误报「目标不存在」
• 私聊机器人不再占用私信额度（冻结 / 封禁账号除外）

** 付款更干净**
• 打开付款窗口不再自动生成订单：选好套餐和网络后点「生成付款地址」才下单；切换套餐会作废上一单

** 给 Agent 用户**
• 任务查询、停止、状态检测按真实情况回报，修掉了几处「报成功其实没做」
• 机器人探查默认先预览；目标安全检查在子项失败时会标明「部分完成」
• 英文界面同步更新

 已知情况：福利里「邀请是否被对方计入」软件无法核实，我们只如实显示机器人自己的回复；macOS 本版暂不更新。

更新方式：软件内「设置 → 检查更新」，或到官网下载安装包。

## 二、详细更新（相比 5.0.17）

### 新增 / 改进

**福利中心**
- Muse 福利改为「10 亿 Token（邀请码领取）」：记到你自己的 Muse 账号名下；支持**两种机器人流程**——直接给邮箱 | 链接凭证的，和要求输入 Muse 邀请码的
- 邀请码两段式：先领 → 机器人要码时账号显示「等待邀请码」→ 填码提交；也可以一开始就填码一次跑完；勾选的**所有账号共用同一个邀请码**；邀请码只在内存里用，本机记录只存后两位
- 风控额度拦在进机器人之前的账号，状态为「额度拦截·可重试」，领取资格没有消耗，额度恢复后可重试
- 判断「不符合」之前会先读会话：停在输入邀请码那一步的账号不会再被误判为没资格
- 新增「机器人邀请」：支持 `https://t.me/<机器人>?start=<参数>`、`t.me/…`、`tg://resolve?domain=…&start=…`；只进入、读首条回复，**不点按钮、不加频道、不付款**；以前进过该机器人的账号默认跳过（可勾选重进）；并发默认 3、号间随机间隔、遇限流自动降并发；机器人要求关注频道时只提示、不替你关注
- 机器人邀请的日志：每个账号每一步都写日志，批次汇总，结果追加到 `runtime/bot_invite_log.jsonl`，界面可导出本链接记录（CSV）；回复里明说「邀请关系已确认」或「无法被邀请 / 已注册用户」的会单独标出
- 首页：福利中心角标 + 非模态提示条，「今天不再提醒」只管今天和当时这批账号；福利窗口工具栏拆成两行，小屏幕不再被撑出屏幕

**批量接管 / 账号**
- 账号池里在线的号可以勾选，开始前软件自动断开它们
- 新增「给勾选的号提供 2FA」（只在内存里用，不落盘）、「从列表移除勾选的」、「清空列表」（只改列表，不删文件）
- 接管时没提供 2FA、号包里也没有，会使用软件里记录的该账号 2FA；预览里会提示
- 接管清单：卖家密钥注销请求没发成功、但旧密钥副本重连已确认失效时，清单会写「已核实失效」；「卖家会话先清其他会话」按真实原因分开说明
- 账号中枢「断开」只断开选中的账号；手动断开不再覆盖封禁 / 冻结等已核实的状态
- 「待连接」账号写明原因（Session 未登录 / 网络线路问题等）
- 多账号会话工作台：全部 / 私聊 / 群组（含频道）/ 机器人 筛选；群组和机器人会话可看历史、手动回复

**群发 / 私信 / 风控**
- 私聊已知机器人不计私信额度、不受号龄分级与红灯（受限）拦截；冻结 / 封禁 / Session 失效 / 接管未完成的账号仍不放行
- 带国家码的纯数字手机号按手机号解析（11–15 位）
- 不存在的 @用户名只尝试一次；解析失败不再重复发同一个请求
- 冻结 / 受限账号解析失败时说明是账号原因

**付款**
- 客户端付款窗口点「生成付款地址」才建单；切换套餐 / 网络作废上一单
- 服务端支持作废订单与到期订单自动清理（晚到的付款仍会补发卡密）

### Agent（MCP）
- `tg_get_task_status` / `tg_stop_task` 能查到所有种类的后台任务（统一发送、养号、加群、群搜索、探查…）；停止回执按真实任务类型命名
- 修复几处「报成功其实没做」：广告点击对没连接的账号、检测状态对不在库的号码、不带任务号的停止
- `tg_probe_bot_features` 私聊探查默认只预览（`dry_run=false` 才真实发送）
- `tg_check_target_safety` 与发送共用同一个解析账号；子项失败时顶层 `partial:true`；`tg_smart_broadcast scan` 的群数只统计本次实时扫描的账号并标明来源
- 超长输入在错误里回显截断到 80 字符；`--serve-mcp` 请求体上限 1MB；数值参数按范围统一校验
- `tg_benefits` 新增 `submit_code`（提交邀请码）与 `bot_invite`（机器人邀请，默认预览、必须指定账号）

### 其他
- 英文界面补全本版新增的文案

## 三、已知限制 / 如实说明
- 「机器人邀请」里**对方是否把这次进入计入邀请，软件无法核实**；我们只能确认「账号进了机器人、机器人回复了什么」。不少机器人禁止用小号刷邀请，可能不计奖励甚至处罚邀请人，使用前请自行评估
- Muse 邀请码提交后机器人的成功回复文案，软件用的是常见措辞的判断，看不懂的回复会标「未确认」，不会当成已领取
- 私聊机器人不计额度是按「已识别为机器人」判断的；重启软件后需要先解析过该机器人才会识别
- macOS 本版不更新；Windows / macOS 安装包均未做代码签名（首次运行可能被系统提示）
- 应用内更新（下载 → 静默安装 → 重启）仍未在大量真机上验证，遇到问题请到官网下载安装包覆盖安装
