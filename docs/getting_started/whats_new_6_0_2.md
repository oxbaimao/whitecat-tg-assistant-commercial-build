### 🌟 v6.0.2 核心升级亮点

#### 🤖 1. Bot API 10.5 零交互主动私信群发（全新可视化面板）
- **无需对方先发 `/start`，直达触达**：在「访客机器人 → 🚀 Bot 10.5 主动私信」页签中，勾选在线健康协议号即可一键批量调用官方 `messages.inviteUsersToBot` 接口，单批邀请 10 人进入专属 Bot 私聊并秒推高转化图文卡片；
- **一键每号配 1 个专属 Bot**：点击「一键每号创建专属 Bot」，自动对接 `@BotFather` 创建或复用并取回 Token（账号曾拉黑 BotFather 时自动解除拉黑重试）；
- **高转化卡片零代码可视化编辑**：支持上传宣传大图（首条自动提取并复用 Telegram `file_id` 极速群发）、HTML 富文本、**绿 / 蓝 / 红三色 Inline 按钮**、**底部双色常驻 WebApp 按钮** 与 **左下角菜单按钮**；
- **导入名单智能保护**：自动过滤 `_bot` 机器人账号、支持断点续发防重复、遇到坏号触发 `BOT_INVITE_USERS_INVALID` 时自动二分拆批跳过坏号，实时展示每个号的邀请、送达与隐私拦截明细。

#### 🎯 2. 群成员采集精准筛选与发言次数统计（新）
- **高净值人群一眼挑出**：在「成员采集」页签新增 **💎 会员号（Premium）**、**🎨 NFT 用户（藏品表情状态 / 配色 / Fragment 域名）**、**8️⃣ +888 匿名虚拟号** 一键筛选（支持「满足任一」或「同时满足全部」）；
- **近期活跃与群组发言次数统计**：支持按过去 3 天 / 7 天 / 15 天 / 1 个月 / 3 个月 / 1 年统计每位群友的真实发言次数，可设置「最低发言次数」门槛，并支持按发言次数排序或采集后本地秒级复筛。

#### 📊 3. 群发实时监控大盘与账号轮休
- 统一群发页顶部实时展示「成功总数 / 失败总数 / 私信收发比」KPI 卡片与 10 列单账号明细表（支持无限循环 `∞` 与任务停止后数据冻结复盘）。

#### 🪝 4. 三段式“钩子”破冰私信漏斗
- 支持「Step 1 极简无敏破冰钩子 → Step 2 互动问句 → Step 3 广告引导」自动持久化推进，杜绝重复发送。

#### 💎 5. 老群 / 老频道资产一键挖掘机 & 入群审批自动关闭
- 「运营分析 → 老群/老频道资产挖掘」一键扫描所有 `creator` 群组与频道，核验建群年月与年限并导出变现资产表；
- 「强拉加群」新增检测与自动关闭「需管理员审批入群（join_request）」及一键通过积压请求。

#### 🎁 6. 24 小时免费试用与高缩放收银台适配
- 新设备免费试用升级至 **24 小时**，放宽共享代理出口 IP 限频；
- 收银台弹窗适配笔记本 150% 高缩放小屏，底部购卡与激活按钮常驻不遮挡。

### 💡 使用建议与已知说明
- Bot 10.5 主动私信建议优先使用状态健康的在线号并绑定**独享静态 IP**，单号建议保持在每轮 6 批（60 邀）以内；
- 成员采集的「发言次数」仅统计所选时间范围内在群内实际发言的消息条数；隐身未公开在线状态的成员无法直接判断最近在线时间；
- 安装包未配置代码签名证书，Windows 首次运行如见 SmartScreen 提示请点「更多信息 → 仍要运行」。
