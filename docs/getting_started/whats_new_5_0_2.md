# 白猫获客 5.0.2 更新说明

> 对外口径：**只说稳定性与兼容性改进，不展开授权 / 试用 / 设备标识的实现细节**（安全相关的内容我们自己知道就好）。技术细节见 `DESIGN_FINGERPRINT_5.0.2.md` 与 WORKLOG（仅内部）。

## 应用内更新弹窗（简短版）
- 稳定性与兼容性改进（授权校验、更新机制优化）
- 功能与 5.0.1 一致

## 说明
- 这是 5.0.1 之后的小版本；功能介绍请看 5.0.1 更新说明。
- 本次发布包含 Windows 与 macOS Apple 芯片（M1–M4）安装包；**macOS Intel 本次没有新包**，请继续使用 5.0.1 的 Intel 安装包，后续补发。
- 如遇授权相关问题，请联系客服并提供「设置 → 激活」里显示的设备编号。

## 已知限制（如实说明）
- **未签名**：Windows / macOS 安装包目前没有代码签名，系统可能弹出安全提示，属于预期。
- macOS 版未在多种 Mac 机型上逐项验证。
