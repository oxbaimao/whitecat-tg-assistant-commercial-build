# 🐱 白猫 TG 自动获客助手 · 旗舰商业版 v6.0.4

> 本版本带来 **手机端「话题群集中接单」**、**会员动态表情代码（wce1_）**、群发 / AI 炒群 / 设置页的大幅改版，并调整了 **免费试用规则**。

---

### 🌟 v6.0.4 新增与改进

#### 📱 1. 话题群集中接单（会话工作台新入口）
- 打开「会话工作台」时可选择接待方式：**电脑端 · 本机多号工作台**，或 **手机端 · Telegram 话题群接单**；勾选「记住我的选择」后下次直接打开，工作台顶栏随时切换。
- **轻量直连模式（免费、无需服务器）**：在 @BotFather 领一个机器人 Token，拉进已开启「话题(Topics)」的群并设为管理员，点「一键自动识别群组并测试」即可连通。之后所有协议号的新线索会在这个群里各自建一个话题，**手机上直接在话题里打字 / 发图 / 发文件，就由原协议号发给客户**。
- 可设置超级管理员，在机器人里发 `/panel` 按 @用户名 授权团队客服代回客户。
- 也支持一码绑定云端双向成交机器人（`wcb1_` 绑定码）。

#### ✨ 2. 会员动态表情代码（wce1_）
- 群发、私信、核对清单都可以直接粘贴表情机器人生成的 `wce1_` 代码，发出去就是会动的会员表情；输入框会实时识别并预览。
- 代码复制不完整时发送前会拦下并提示，不会发出乱码；非会员号自动改发纯文本。
- 核对清单（Checklist）需会员号发送，非会员号自动跳过。

#### 📢 3. 群发页改版
- 语音条 / 圆形视频 / 来电提醒、名片 / 内联机器人、投票 / 核对清单、私信触达顺序 & 对方动态改为点按钮弹窗配置，主界面更清爽。
- 实时监控大盘可弹出成独立悬浮窗，一边改内容一边盯数据。

#### 🔥 4. AI 炒群
- 新增「夜间慢速」（北京时间深夜自动放慢发言）、「随机点赞」、账号编号对齐模式、马甲角色表格直接编辑。
- 可选把群里真人的发言转给你指定的人 / 群，方便人工接管（默认关闭）。

#### ⚙️ 5. 设置页重排
- 账号风控额度三种模式（按号龄分级 / 自定义 / 关闭拦截）的说明与号龄判定规则一目了然；老号导入即可从更高阶段起步。
- 新增「主流 Agent 一键配置中心」：自动识别本机的 Claude Code、Codex、Cursor 等并写入 MCP 配置、完成真实握手验证。
- AI 接口支持「MCP Agent 代答」模式、独立看图 / 语音识别模型、ElevenLabs 语音合成。

#### 🧭 6. 其他
- 「间谍获客」从侧边栏和首页工作流下线。
- 启动切换到主窗口时不再白闪。

#### 🎁 7. 免费试用规则调整
- 免费试用 **每台电脑只送一次**，删除数据、重装软件不会重新发放；已有卡密可以直接激活。
- 免费试用期间 **最多 3 个 Telegram 账号同时在线**，**不含「自动化流水线」与「会话 AI 接待」**；购买授权并激活后立即全部解锁（账号状态显示「待连接 · 试用限额」的，点「全部连接」即可上线）。
- 付费用户不受任何影响。
