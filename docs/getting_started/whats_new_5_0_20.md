### v5.0.20 核心重磅升级

#### 1. 频道克隆与内容搬运：万条并发、断流自愈
- **补发上限提升至 10,000 条**：单次可直接搬运多达 1 万条优质历史图文/视频，轻松打造高权重行业大频道；

- **支持私密及无用户名频道**：直接输入 `-100...` 数字 ID 或从账号已加入列表一键勾选，搬运无死角。

#### 2. 账号资产体检：全群退群与待发定时消息扫描
- **批量安全退群**：账号加满 500 群无法加新群？一键扫描账号已加入的全部超级群与频道，按关键词精准搜索、批量安全退出；

#### 3. 客户接待与会话工作台：效率翻倍
- **全新四栏分栏自适应布局**：账号、会话、聊天、潜客资料一目了然，昼夜主题高清晰对比，消息气泡左右分明；
- **快捷话术一点即填**：沉淀常用促成话术，单机一键填入，跟进快人一步；
- **附件防误触保护**：多图与大文件先挂载预览，点击发送才正式投递，防止错发漏发。

#### 4. AI 智能体生态（全量 60 项 MCP 标准工具）
- **会话媒体文件全量归档**：支持 Agent 一键检索并下载群聊/频道/私聊内的图片、视频、语音、文档，并严格核验完整性；
