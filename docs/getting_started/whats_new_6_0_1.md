# 白猫 TG 自动获客助手 · 旗舰商业版 v6.0.1

> 这是 6.0.0 的修复版，建议所有 6.0.0 用户更新。

### 修复
- **猫管家「模型设置」窗口反复报错**：点取消 / 关闭窗口后，运行日志里每秒出现一条「没有属性 controller」的错误。已修复，窗口关闭后不再残留后台刷新。
- **模型设置窗口文字互相压住**（macOS 上更明显）：内容改为可滚动，窗口高度不会超过屏幕；macOS 补了系统中文字体回退。
- **新手指引**：适配 6.0（新增「对猫管家说」「猫管家按钮」两步）；目标在首页下方时自动滚到可见位置；说明文字不再被截断。

### 已知限制
- macOS 上界面整体偏大的问题还在排查，未包含在本版。
- 猫管家、手机遥控的真实 Telegram 场景仍只在本地测试环境验证过，建议先用小号试用。
- 安装包均未做代码签名（macOS 未公证），首次打开需放行；应用内更新流程（含 macOS）未在真机验证。
