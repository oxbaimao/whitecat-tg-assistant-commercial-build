# 5.0.14 更新说明

> 写给付费客户的人话版。没在真实环境验证过的地方，下面都写明了。
> **本版目前只发布 Linux；Windows / macOS 暂未随本版发布。**

## 云端虚拟机里的多台实例，不再被当成「同一台设备」
- 以前：Muse / GrokBot 这类云端助手的虚拟机通常从同一个镜像克隆，主机名、用户名、系统标识完全相同，Linux 上又没有磁盘序列号，于是不同客户的虚拟机在授权服务器眼里变成同一台设备——卡密到期日会叠加、「找回卡密」可能看到别人的卡、不同实例还会互相顶掉设备绑定。
- 现在：**Linux 上全新安装**时，软件会在授权数据目录里生成一个随机的安装标识（只留在本机，不上传原文），设备编号由它派生，每个实例各算各的。
- **已经装过、已经激活过的不受影响**：升级后保持原来的设备编号，不会变成新设备。
- 如实说明的代价：**把授权数据目录删掉 / 换一台虚拟机重新开始，会被当成新设备**。一张卡同一时间只能占一个设备席位，旧的席位需要先释放（联系客服，或用自助解绑）。想保持稳定，请把数据目录固定在一个会保留的位置（环境变量 `WHITECAT_DATA_DIR`）。
- 如果你手上有两台实例以前共用了同一个设备编号：升级后它们**不会自动分开**。让其中一台清掉授权数据目录、再用新版重新激活，它就会得到自己的设备编号。

## 注意（如实）
- 这项改动**没有在真实的 Muse 虚拟机里验证过**，只做了模拟测试；建议第一次先用一张测试卡走一遍「下载 → 激活 → 重启 → 再激活」。
- 本版不含其它功能改动。
