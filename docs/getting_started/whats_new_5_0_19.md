# 白猫 TG 助手 5.0.19 更新说明（面向用户）

> 相比 5.0.18：关键词监控可以选「命中黑名单后是否继续通知」；转化流水线的私信可以发图片 / 语音 / 名片等丰富内容；会话工作台升级为「统一收件箱」。MCP 工具数不变（60 个）。
> 平台：Windows · Linux 便携包。macOS 版本由 Mac 机器单独构建，发布时间另行通知。

---

## 一、频道公告（可直接转发）

**🐱 白猫 TG 助手 5.0.19 来了**

**🔔 关键词监控：黑名单命中后可以不再通知**
• 编辑监控规则里，「通知转发到」下方多了一个选择框 **「命中风控黑名单的发信人后，仍然继续通知」**，默认勾选（和以前一样）
• 取消勾选后：黑名单里的发信人命中只会记录在命中列表里并标红，**不转发通知、不推 Webhook、也不会进入转化流水线**，状态里会写明「已跳过」及原因

**📨 转化流水线：私信内容和「私信群发」一样丰富**
• 流水线设置里新增「发送内容」：图片相册、文件、语音条、圆形视频、联系人名片、内联机器人图文帖、触达顺序（如先图片再文字）、浏览 / 点赞 / 回复动态、响铃提醒
• 与私信群发用的是同一个发送器，账号风控额度、限流冷却、换号、对方隐私限制等原有保护照常生效；没发出去的不会被记成「已联系」
• 不勾选「发送内容」时，行为和以前完全一样（纯文字）

**💬 会话工作台 → 统一收件箱**
• 新增「📥 统一收件箱」：所有在线账号的会话合并成一张列表，按最后消息时间排序，显示未读数；可「只看未读」
• 支持多选后批量 **标记已读 / 拉黑 / 删除会话**（拉黑和删除会先确认）
• 新增 **客户备注**（按对方 Telegram ID 记在本机）、**快捷回复话术**（支持 `{你好|您好}` 随机和 `{name}`）、**发送图片 / 文件**

**🤖 Agent（MCP）**
• `tg_desk_leads` 新增收件箱动作：合并收件箱、读消息、标记已读、客户备注、快捷回复、以指定账号回复（默认只预览，真实发送要明确确认，发送后回读核实）
• `tg_pipeline_control` 的流水线配置支持 `send_options`（同上的丰富内容）

## 二、需要如实告知的

- 本版新增功能以离屏自动化测试为主，**在真实 Telegram 下尚未全部验证**（图片 / 语音 / 圆形视频 / 动态 / 内联机器人在流水线里发出、已读回执、拉黑与删除会话、发文件）
- 「已读」只能确认已发送已读回执，Telegram 不提供回读已读状态
- 统一收件箱每个账号只读取最近 100 个会话
