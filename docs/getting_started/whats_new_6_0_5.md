# 🐱 白猫 TG 自动获客助手 · 旗舰商业版 v6.0.5

> 本版本主要解决客户反馈的几个老大难：**明明能发却提示「双向受限」**、**自动回复「正在输入」却没发出去**、**话题群里收不到消息**，并新增 **群置顶消息的高级 emoji 反应**。

---

### 🌟 v6.0.5 新增与改进

#### 🛡 1. 双向受限的号，现在能干的事更多了
- Telegram 的「双向受限」只限制 **主动私信陌生人** 和 **拉人进群**。以前软件把它当成整个账号被隔离，群里发言、回复也一起停了。
- 现在双向受限的账号 **可以在群里发言、群聊群发、进群，也可以回复对方先发来的私信**（自动回复不占私信额度）；只有主动私信陌生人、拉人会被暂停，提示里写的是真实原因，不再出现「上限 0 次、约 24 小时后恢复」这种假数字。
- 冻结、封禁、Session 失效、接管中的账号仍然一律不发。
- **「🧪 实测私聊」能真正解除了**：支持按「表格已选 / 全部在线 / 仅双向受限 / 各账号分组」选择账号；用一个没加过好友、没聊过天的号当测试对象，探测消息自动豁免双向与养号额度拦截，对陌生人发送成功后，账号状态回到在线，**风控红灯也一并清除**（以前只改了界面上的状态，重启就变回去）。测试对象如果是联系人或以前聊过，软件不会发，也不下结论。
- 识别 +91/+57 等号段在 @SpamBot 下的「号码可能触发严格风控」软提醒，悬停说明与检测弹窗直接引导使用「实测私聊」或「🔓 放行红灯号（新增主动私信陌生人选项）」验证可用性。
- 临时受限到期后会提示「建议重新检测」；@SpamBot 回复「限制已解除」会被当作正常；账号表里把鼠标放在「双向受限」上能看到通俗解释和判定依据。

#### 💬 2. 自动回复重做
- **不再「正在输入」却不发**：先判断这个账号能不能回复，再显示「正在输入」；不能回复就不显示，并在日志里写真实原因。
- 新增「账号就绪」表：每个账号能不能自动回复、为什么、本次已回复几条，30 秒刷新。
- 多个账号收到编号相同的私信不再被吞；同一个客户连发几条，固定话术只回一次。
- 对方 **只发图片 / 贴纸 / 语音** 也会回复（可关）。
- AI 失败时 **不再给客户发「我刚才走神了」** 之类的话：没配置就不回并写明原因，也可以设置自己的兜底话术。
- 账号断线重连后，自动回复会自动重新挂上；界面和 MCP 共用同一个自动回复，不会重复回复。日志也不再每条写两遍。

#### 📱 3. 话题群集中接单：权限自检，客户消息不再丢
- 点「一键自动识别群组并测试」后，软件逐项检查：网络 / Token / Webhook / 话题群 / 机器人是不是管理员 / 有没有「管理话题」权限 / 能不能收到群里客服打的字，并告诉你怎么改，Webhook 冲突可一键清除。**全部通过才显示「连接成功」。**
- 机器人没有建话题权限时，客户消息 **不再丢**：先发到群的 General 区，**直接回复那条消息就由原协议号代回**；暂时发不出去的会暂存、自动补推。
- 网络 / 代理出问题时，错误提示写明是哪一种（代理、网络、令牌被别处占用…），并按 3→60 秒逐级退避，不再每 3 秒刷屏。

#### ✨ 4. 群置顶消息表情反应（支持会员高级 emoji）
- 统一群发的群聊群发里新增「📌 给群置顶消息点表情反应」：可以 **先点反应再发文案**，也可以 **只点反应、不发消息**。
- 表情可以写高级 emoji 的 ID、`wce1_` 代码、`t.me/addemoji/表情包名`，或普通 emoji。
- 群不允许高级 emoji 时：重试 1 次，仍不行就 **降级为该群允许的普通 emoji**（可关，关了就跳过该群）；群关闭了反应、没有置顶消息、没有权限的，跳过并写原因。点完会回读核实，**回读不到就写「未核实」，不算成功**。
- 私信群发的「点赞动态」、AI 炒群、剧本炒群的点赞也用同一套规则。

#### 😀 5. 会员表情代码（wce1_）全面生效
- 以前只有统一群发能把 `wce1_` 代码变成会动的会员表情，其他地方会把原始代码串发出去。现在 **自动回复、会话工作台、话题群代回、AI 炒群、剧本炒群、MCP 群发** 都会正确展开；非会员号自动改发纯文本；代码不完整会拦下提示，不会发出乱码。
- 自动回复话术框、会话工作台输入框会实时提示识别到几个会员表情。

#### 🤖 6. AI Agent（MCP）工具 62 → 65 项与猫管家升级
- 新增 `tg_reactions`（置顶 / 动态反应与预览）、`tg_premium_emoji`（会员表情解析 / 生成 / 表情包 / 会员查询）、`tg_topic_bridge`（话题群状态、权限自检、清除 Webhook、补推暂存线索）。
- `tg_check_account_status_full` 可顺带做「实测私聊」（默认只预览）；`tg_manage_proxies` 新增 `confirm_drift`（预览或确认「代理变更待确认」账号切换到新代理并自动重连）；`tg_force_invite` 默认支持未进群账号自动先进群；自动回复相关工具补充了「只发图片也回复」「AI 兜底话术」。
- **猫管家「计划模式」一键执行**：在计划模式下生成方案后，输入框上方直接出现「▶ 批准计划并切到自动模式执行」按钮，不再出现不知道去哪点确认的死胡同。

#### 🚀 7. 获客动线提速与「🌱 极简模式」
- **统一群发（群聊群发）新增「🔗 贴群链接 / 主号导群」**：除了扫描勾选已进的群，现在可以直接粘贴群链接 / `@用户名`（未进群的小号自动先加群并过验证），还能点「📥 从观摩号/主号提取群列表」一键把主号里的公开群导出来、自动取消勾选主号，只让小号去发广告。
- **强拉加群一条龙**：默认开启「拉人账号不在目标群时，自动先进群（支持过进群验证）」，不用先跑一遍批量加群。
- **Bot 10.5 主动私信**：修复目标用户此前已启动过该机器人（`BOT_INVITE_ALREADY_STARTED`）时误判账号受限停号的问题，自动拆批直达发卡；加宽三色/双色按钮输入框并支持裸用户名自动补全 `https://t.me/`。
- **顶栏新增「🌱 极简模式 / 🛠 全部功能」一键切换**：新手切到极简模式后，侧边栏只保留账号、代理、采集、群发、私信、Bot 10.5、强拉、自动回复与会话工作台等核心功能（按 `Ctrl+K` 仍可随时搜索全部 22 个模块）。
- 作废的 Session（同一个 Session 被两个 IP 同时使用而被 Telegram 注销）：日志直接写「Session 已作废，需要重新登录或换号」，**启动和「全部连接」不再反复去连它**，只在汇总里写一次「N 个 Session 已作废，未连接」（想再试可在账号页点「检测」）。
- 启动时自动恢复连接的日志写「已连接」，不再每次都显示「导入成功」。

### 💡 客户使用提示
- 双向受限账号的群内发言、回复私信，以及置顶反应、话题群权限自检，目前只做过离线测试，**还没有在真实 Telegram 上逐项验证**。建议先用一个会员号、一个双向受限号、一个测试话题群小批量试一轮，再大批量使用。
- 双向受限的号在群里发得过多仍可能被 Telegram 进一步限制，额度依然按号龄分级，请不要一次发太多。
- 安装包未配置代码签名证书，Windows 首次运行如见 SmartScreen 提示请点「更多信息 → 仍要运行」。
