# v5.0.9 更新说明

> 5.0.8 的功能请看 [v5.0.8 更新说明](whats_new_5_0_8.md)。

> 写给付费客户的人话版。

## 新功能
- **群发可以「按群名分流」了（像漏斗：群名带「北京」的发北京版内容，带「上海」的发上海版内容，互不串）**：在「 群聊群发」里勾选「 按群名分流发送（漏斗）」，点「设置分流规则…」，每条规则填：
  - **规则名称**（如「北京」）和**群名关键词**（如「北京, 京」）——群名或用户名里带这些词的群，自动归到这条规则（来自你的账号已经加入的群，先点「扫描账号已加入的群」）。不只是地区，按行业、语言、客户类型分都行；
  - **要发的内容**，两种写法：直接写文案（可加专属图片）；或者先在主页面把整套内容设置好（富文本、图片、文件、语音、圆形视频、转发并置顶、投票、联系人名片…），再点「保存页面当前内容」存给这条规则——**和不分流时能发的内容完全一样**；
  - **专属账号**（可选）：勾了就只用这些账号发这条规则，比如「北京号」只发北京的群；一个都不勾就用你在主页面选的全部账号。
  - **范围**：下面的群列表里勾选了群，就只在勾选的群里分流；一个都没勾，就在你所选账号加入的全部群里分流。确认框会写明这一点。
  - 可选「没命中任何规则的群，也用主页面当前的内容发送」（默认不发）。
  - 每条规则**单独发送**，内容只会发到命中它的群。点「预览分配」能先看到每条规则发多少个群、用哪些账号。
  - **同一个群同时命中两条规则**（比如群名叫「北京上海同城群」）时，软件**不会发**，并在预览和结果里列出来，让你改关键词或手工指定——宁可漏发，也不发错内容。
  - Agent 通过 MCP 的 `tg_smart_broadcast`（`start` 时传 `routes`，每条规则可带自己的完整发送选项）也能用，同样默认先预览。
- **剧本炒群支持「随机点赞」**：在「预设剧本回放」里勾选「随机点赞」，剧本账号发言后，其他剧本账号会按你设的概率（默认约三分之一的消息）、稍等几秒，随机给它点一个正能量表情（ ，表情和概率、每条最多几个账号来点都可以改）。
  - 点完软件会回读核实，读不到的只记「点赞未核实」，不算成功；
  - 带 `<时:分:秒>` 的定时行由 Telegram 到点发出，软件拿不到消息编号，所以只有实时发出的行会被点赞；
  - 如果群管理员限制了可用表情或关了点赞，软件会自动停止点赞并在结果里写明原因，剧本照常演完。
  - AI 炒群本来就支持点赞，这次补上的是预设剧本这一种。

- **新增 Linux 版（64 位，x86_64）**：下载 `…-Linux-x64-Portable.tar.gz`，解压后在图形桌面里运行 `./start.sh`（首次可能需要 `chmod +x`）。需要 X11 / Wayland 桌面；缺运行库时按压缩包里 `README_使用说明.txt` 的提示用 `apt` 安装。语音条 / 圆形视频转码需要系统装有 ffmpeg（`sudo apt install ffmpeg`，Linux 版暂不内置）。无桌面的服务器可用 `./启动MCP服务.sh` 作为 AI Agent 的 MCP 命令。暂不支持软件内自动更新（请手动下载新版）；Linux 版目前没有在真机上跑过完整流程，欢迎反馈。

## 改进
- **图标的猫耳朵补全了**：之前图标里猫的两只耳朵尖是被削平的，现在是完整的尖耳朵（桌面、任务栏、软件内图标、官网图标都已更新；Windows 有图标缓存，升级后如果还是旧的，注销重新登录或重启一次电脑即可）。
- **群发默认不再「提示双向后原地反复重试」**：以前默认让同一个账号在提示双向后连续重试 10 次，容易让受限账号越撞越久。现在默认 0（不重试，直接换下一个账号）；想要重试的话，在「防封与重试策略」里自己把「提示双向后尝试次数」调大，旁边写明了风险。
- 修复：弹窗被自动关闭的定时器碰上用户已手动关掉弹窗时，偶发的「wrapped C/C++ object of type QMessageBox has been deleted」报错。
- 修复：「搬运」排队很久后报「The file reference has expired」——现在发送前会先从源频道重新读取消息，换上新的文件引用；读不到（源消息已删除）会写明原因。
- 修复：群聊群发里没勾选任何群时，提示可以点「放大窗口选群」批量勾选；「放大窗口选群」里的「全选」按钮点了不刷新表格的问题。
- 官网同款的「 30 秒介绍视频」按钮只在官方版的首页显示。

## 注意
- 按群名分流发送暂不支持「自动修复没人能发的群」（勾选了也不会生效，结果里会提示）。
- 以上两个功能都还没有在真实 Telegram 里实测过（软件内部测试用的是模拟账号），首次使用请先用小号、小批量试一下。
- 同一批账号不要在两台电脑（或两个软件）里同时登录：同一个 session 在两处同时使用会被 Telegram 作废，需要重新登录。
