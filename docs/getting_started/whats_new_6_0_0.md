# 白猫 TG 自动获客助手 · 旗舰商业版 v6.0.0

> 本次更新的重点：**软件里多了一个「猫管家」页，用一句话就能让它帮你干活；手机上也能遥控。**
> 下载地址与校验码见仓库 README 的下载表，官网与 GitHub Release 提供的是同一批文件。

---

### 本次更新了什么

#### 1. 猫管家（新）
- 主窗口新增「猫管家」页：接入你自己的模型服务（填接口地址、模型名和密钥），用自然语言说需求，AI 通过软件自带的 62 项工具真实执行。
- **有副作用的动作先出确认卡**，你批准才执行；可在「询问 / 计划 / 自动 / 完全放开」之间切换。「完全放开」需要输入确认短语，放开后连验证码、密码这类内容也会随对话发给你的模型服务商，请自行评估。
- 支持把文件和图片拖进来或 Ctrl+V 粘贴截图；图片会作为图片发给模型（**模型需要支持看图**，不支持时软件会如实告诉你"这次没有看到图片"）。
- 多会话（主要聊天 + 旁聊），对话自动保存；点「停止」会给出真实发生了什么的报告；任务进行中会显示「处理中 · 已用时」。
- 这一块还没有在大量真实 Telegram 场景里验证，建议先用小号试用。

#### 2. 手机遥控（新）
- 用你自己的 Telegram 机器人，在手机上对话、批准动作。配对只认你本人，关键动作需要两步确认。
- 需要先在猫管家设置里填机器人 token 并生成配对码。真实机器人连接尚未大范围验证。

#### 3. AI 打开网页并核实结果（新工具 `tg_browser`）
- MCP 工具增加到 **61 项**。用不被程序驱动的无痕窗口打开链接（避免被人机验证拒绝），再用业务状态核实结果，例如"群里发言限制是否真的解除"。也能无头只读读取页面。
- 它不会替你点击或输入。

#### 4. 语音合成（新工具 `tg_tts`）
- MCP 工具增加到 **62 项**。AI 可以把文字变成语音：支持 **ElevenLabs**（在设置 → 语音合成里填你自己的 API Key 和 Voice ID）或**系统自带语音**（Windows / macOS，本地、免费）。生成的音频可直接作为「统一群发」的语音条，或在 VoIP 电话里播放。
- 默认只预览，真实合成才会消耗 ElevenLabs 额度；API Key 加密保存在本机，请不要发到聊天里。
- 系统没有中文语音包时，软件会如实告诉你，不会用英文语音念中文。
- ElevenLabs 部分只用假接口测过，还没有用真实账号验证；系统语音在 Windows 上真实生成过一段中文音频。

#### 5. 其他
- 账号压缩包（session / tdata）可直接导入；聊天里的文件可下载、聊天记录可导出；SaaS 线索联动。
- **强拉默认先预览**，不再一上来就真实执行。
- 群发完成后的回读摘要按项目分别列出。
- MCP 只读模式（`--read-only`）的限制补全。

#### 6. 界面改版
- 双栏导航（图标栏 + 功能列表，切换时列表栏滑动展开 / 收起）、扁平胶囊按钮、浅色配色；徽标去掉光晕更清晰，猫放在标题栏。
- 首页改版：「对 AI 说」输入行；发送记录可按账号 / 状态 / 时间范围筛选并带统计条；运行中的任务实时显示已运行时间、进度和成功 / 失败条数（统一群发、成员采集、强拉、批量加群等已接入）。
- 高分屏的缩放取整方式调整，如果你发现某些界面在高缩放下显示异常，请告诉我们。

---

### 已知限制（如实说明）
- 猫管家、手机机器人、`tg_browser` 的真实浏览器 / 人机验证场景，目前只在本地测试环境验证过，未在大量真实账号上验证。
- 猫管家只测试过部分模型；图片功能需要支持看图的模型。
- macOS 包由 Mac 机器编译，未做代码签名与公证，首次打开需在「隐私与安全性」中放行；自动更新替换 .app 的流程未在真机验证。
