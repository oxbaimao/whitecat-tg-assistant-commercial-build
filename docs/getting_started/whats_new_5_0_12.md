# 5.0.12 更新说明

> 写给付费客户的人话版。没在真实环境验证过的地方，下面都写明了。

## 让 AI Agent（Muse 等）一句话装好、接好
- **新增 `--agent-setup`**：一行命令输出 JSON 自检 / 激活结果——授权服务器连得上吗、激活成功了吗、失败是哪一类原因、下一步该做什么，Agent 照着做就行。
- **新增 `--serve-mcp`**：软件自带本机 HTTP MCP 端点（`http://127.0.0.1:8765/mcp`），Muse 这类通过「自定义连接器」接入的 Agent 直接填地址即可，不用再自己写桥接。默认只接受本机请求；要对外必须设置令牌。
- **官网新增「给 AI Agent 的安装说明」**（`/agent-install.md`）、机器可读的版本清单（`/downloads.json`，含各平台版本、直链、大小、SHA256）和 Linux 安装脚本（`/install.sh`，先读后跑）。
- **激活不再被「拦截式网络出口」卡住**：授权与更新请求现在同时信任系统证书库和软件自带证书库；仍失败时，把出口根证书放到数据目录的 `extra_ca.pem` 即可，升级不会被覆盖。

## 设备密钥变了，自己就能恢复
- 重装、清数据目录、Agent 的虚拟机被重置后，设备密钥会变，以前激活会 403 只能找客服。现在**用这台设备之前激活过的那张卡密再激活一次**，服务器会自动恢复绑定（服务器已升级，现有版本也可以用；同一台设备 30 天最多 3 次）。拿新卡密直接激活不行，会提示先用原卡密。建议把数据目录固定下来（环境变量 `WHITECAT_DATA_DIR`）。

## 注意
- 以上都**没有在真实的 Muse 虚拟机里验证过**；自助换绑在服务器侧已上线，但还没有真实客户用过。
- 「一键信任出口证书」没有做（涉及信任策略，需要你确认），目前只支持手工放入证书文件。
