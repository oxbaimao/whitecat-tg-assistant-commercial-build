# 🐱 23. 猫管家：用一句话让软件帮你干活（6.0 新）

> 💡 **一句话结论**：猫管家是软件里的 AI 助手。你用自然语言说需求，它调用软件自带的工具真实去做；**有副作用的动作先给你看确认卡，你点头才执行**。它用的是你自己的模型额度。

---

## 一、第一次使用：填模型接口（约 1 分钟）

猫管家本身不带模型，需要你填一个**兼容 OpenAI 接口格式**的模型服务（DeepSeek、OpenAI、本机 Ollama 或任何兼容的聚合平台都可以）。

1. 点首页「对猫管家说」输入框，或顶部的「🤖 猫管家」按钮；第一次会提示去填写模型设置；
2. 在「猫管家 · 模型设置」里选**预设**（deepseek / openai / ollama / 自定义），会自动带出接口地址和模型名；
3. 填你自己的 **API Key**（加密保存在本机）；
4. 点「保存」。如果「设置」里已经配过 AI 接口，可以点「沿用『设置』里的 AI 配置」。

> 🔒 **隐私**：对话内容会发送给你填写的模型服务商。发送前账号手机号会先换成「账号A / 账号B」这样的别名；**验证码、密码、密钥不会进入对话**。
> 如果暂时没有可用的 API，可以到聚合平台获取：<https://uuapi.co>（第三方服务，按其条款使用）。

**工具范围**（设置里可选）：
- **全部工具**（默认）：和软件、MCP 能做的事一致，每轮对话会多消耗约 2.6 万 token；
- **精简**：只给 8 个常用工具，省 token，但很多事做不了。

## 二、怎么说话

直接说你要做什么，例如：

- 「看看今天哪些账号能发消息」
- 「哪些账号还没绑代理？」
- 「导入我的账号压缩包」（可以直接把文件拖进聊天窗口）
- 「监听这几个群里出现『求购』的消息，命中后通知我」

猫管家会先查真实数据再回答；**没有账号或读不到数据时，它会明确告诉你，不会编造数据**。

### 附件
- 把文件（账号压缩包、tdata、文本等）或图片拖进窗口，或 `Ctrl+V` 粘贴截图；
- 图片会作为图片发给模型，**需要你的模型支持看图**，不支持时软件会如实告诉你「这次没有看到图片」。

### 多会话与停止
- 左侧可以新建对话；对话自动保存；
- 任务进行中会显示「处理中 · 已用时」；点「停止」会给出一份**真实发生了什么**的报告，不会假装没做。

## 三、权限模式：哪些事会先问你

右下角可以切换模式。动作按风险分档：

| 动作类型 | 询问 | 自动 / 接受本机改动 | 计划 | 完全放开 |
| :--- | :--- | :--- | :--- | :--- |
| 只读查看（查账号、查状态） | 直接做 | 直接做 | 直接做 | 直接做 |
| 本机改动（改配置、绑代理） | 确认卡 | 直接做 | 只预览 | 直接做 |
| 对外动作（发消息、加群、拉人） | 确认卡 | 确认卡 | 只预览 | 直接做 |
| 关键动作（不可逆 / 影响大） | 强确认卡 | 强确认卡 | 只预览 | 直接做 |

- **计划模式**：只出方案和预览，什么都不真正执行；
- **完全放开**：需要输入确认短语，并且放开后验证码、密码这类内容也可能随对话发给你的模型服务商，**请自行评估后果**。设置里的「记住『完全放开』」默认关闭，只对当前对话生效。

### 没有代理就连接账号
如果某个账号**没有绑定专属代理**，猫管家连接它之前会弹出授权确认：没有代理时它会走你这台电脑的本机网络，和别的号共用一个 IP，容易被关联。建议先导入代理，再让猫管家预览「一号一 IP」的绑定方案。

## 四、常见问题

**Q：提示「请先填写模型接口地址、模型名和 API Key」？**
A：按上面第一节填写；如果用的是 Ollama，API Key 可以留空。

**Q：设置窗口反复报错或文字被压住？**
A：这是 6.0.0 的问题，**升级到 6.0.1** 已修复。

**Q：猫管家说「做完了」，怎么确认是真的？**
A：发送、拉人这类动作，软件会回读核实（消息是否真在对话里、对方是否真在群里）；做不到核实的会写「未核实」。

**Q：它能自动付款或点购买按钮吗？**
A：默认不会。点击购买 / 支付按钮这类动作默认关闭，需要你明确放开。

> ⚠️ **如实说明**：猫管家目前只在本地测试环境验证过，没有在大量真实 Telegram 场景里验证，**建议先用小号、小范围试用**。
